## Privacy & Redaction Policy (중요)

이 레포는 **공개 저장소 기준**으로 운영합니다.  
따라서 아래 항목이 포함된 문서는 **반드시 마스킹(redacted)** 후 업로드합니다.

- 주민등록번호/생년월일/학번/수료번호/식별번호
- 주소/전화번호/이메일
- QR/검증코드/인증 URL(검증 토큰 포함 가능)
- 서명/도장(필요 시)
- **제3자 실명**(팀원·확인자·담당자). 본인 이름은 남깁니다

> 원본(무마스킹) 문서는 **업로드하지 않습니다.**  
> 검증이 필요한 경우 요청 시 별도 채널로 제공할 수 있습니다.

### 검수 이력

포트폴리오 게시 시점에 **전량 점검**했습니다.

- 텍스트 레이어가 있는 문서는 정규식으로 민감 패턴(휴대폰·유선전화·생년월일·군번·학번)을 훑었습니다.
- 텍스트 레이어가 없는 스캔 원본은 게시본을 **눈으로** 확인했습니다.

> **마스킹 누락은 전부 스캔 이미지 또는 표 형식 서식에서 나왔습니다.**
> 자동 검사가 닿지 않는 유형이므로, 새 자료를 넣을 때는 반드시 게시본을 눈으로 확인해야 합니다.

가림 처리는 모자이크가 아니라 **불투명 사각형**으로 합니다 — 모자이크는 복원되는 경우가 있습니다.
어느 문서에서 무엇이 누락되었는지는 이 저장소에 적지 않습니다(공개 문서이므로).

## Repository Structure
- `index.md` : 문서 목록(발급기관/날짜/요약/관련 링크)
- `reports/` : 보고서/산출물
- `evidence/` : 상장/이수증/참여 증빙
- `evidence/awards/` : 수상 관련 증빙
- `evidence/certificates` : 자격/인증/공식 수료 증빙
- `evidence/training/` : 교육/훈련/프로그램 이수 증빙
- `evidence/participation/` : 참여/활동/선발/발표/기여 증빙
- `reports/index.md` : 보고서 발췌 원칙과 목록
- `reports/figures/` : 보고서에서 발췌한 분석 화면 캡처
- `reports/papers/` : 발표 논문의 제목·요약 캡처
- `media/` : README/인덱스에서 사용하는 스크린샷(선택, 현재 비어 있음)
